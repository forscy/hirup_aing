# Role dalam Aplikasi Hirup Aing dan Fungsinya

Untuk aplikasi Hirup Aing akan digunakan sehari hari untuk:
1. Mencatatat Aktivitas yang akan dikerjakan
2. Mencatat riwayat Aktivitas yang telah dicatat
3. Menijau kinerja dari setiap kegiatan
dan seterusnya akan dilanjutkan di user story

## 1. Admin

**Fungsi:**
- Mengelola semua data master di seluruh sistem

## 2. User

**Fungsi:**
- Menggunakan aplikasi

**Biasanya dimiliki oleh:** Pemilik bisnis atau pimpinan tertinggi
