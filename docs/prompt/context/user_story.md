# User Story Aplikasi Hirup Aing

## 1. Admin

1. Sebagai seorang Admin, saya ingin dapat melihat semua user yang terdaftar dalam sistem agar saya bisa memantau pengguna aplikasi.

2. Sebagai seorang Admin, saya ingin dapat melihat semua aktivitas dari semua user agar saya bisa memantau penggunaan aplikasi.

3. Sebagai seorang Admin, saya ingin dapat melihat statistik penggunaan aplikasi agar bisa mengevaluasi performa aplikasi.

4. Sebagai seorang Admin, saya ingin dapat menambahkan kategori sistem yang dapat digunakan oleh semua user agar memperkaya pilihan kategori.

## 2. User

1. Sebagai seorang User, saya ingin dapat mendaftar dengan email dan password agar memiliki akun pribadi untuk mencatat aktivitas saya.

2. Sebagai seorang User, saya ingin dapat login ke akun saya agar bisa mengakses catatan aktivitas pribadi saya.

3. Sebagai seorang User, saya ingin dapat logout dari aplikasi agar memastikan akun saya aman ketika tidak digunakan.

4. Sebagai seorang User, saya ingin dapat membuat kategori aktivitas baru agar bisa mengorganisir aktivitas saya sesuai kebutuhan.

5. Sebagai seorang User, saya ingin dapat membuat aktivitas baru dengan detail lengkap (nama, deskripsi, waktu mulai, waktu selesai) agar bisa merencanakan kegiatan dengan baik.

6. Sebagai seorang User, saya ingin dapat menentukan frekuensi pengulangan aktivitas (harian, mingguan, bulanan) agar tidak perlu membuat aktivitas yang sama berulang kali.

7. Sebagai seorang User, saya ingin dapat menentukan hari spesifik dalam seminggu untuk aktivitas mingguan (misal: setiap Senin, Rabu, Jumat) agar aktivitas terjadwal sesuai kebutuhan.

8. Sebagai seorang User, saya ingin dapat menentukan tanggal spesifik dalam sebulan untuk aktivitas bulanan (misal: setiap tanggal 1 dan 15) agar kegiatan terjadwal tepat pada tanggal yang diinginkan.

9. Sebagai seorang User, saya ingin dapat menetapkan satu atau lebih kategori untuk setiap aktivitas agar pengorganisasian aktivitas lebih fleksibel.

10. Sebagai seorang User, saya ingin dapat melihat semua aktivitas saya untuk hari ini agar bisa merencanakan hari dengan baik.

11. Sebagai seorang User, saya ingin dapat melihat semua aktivitas saya untuk tanggal tertentu agar bisa melihat jadwal di masa lalu atau masa depan.

12. Sebagai seorang User, saya ingin dapat memperbarui status aktivitas menjadi "Selesai", "Ditunda", atau "Batalkan" agar bisa melacak progres kegiatan saya.

13. Sebagai seorang User, saya ingin dapat menambahkan catatan pada instance aktivitas agar bisa mencatat detail tambahan tentang pelaksanaan aktivitas.

14. Sebagai seorang User, saya ingin dapat mengedit detail aktivitas master (nama, waktu, deskripsi, dll) agar bisa menyesuaikan jika ada perubahan.

15. Sebagai seorang User, saya ingin dapat menghapus aktivitas yang tidak relevan lagi agar daftar aktivitas tetap teratur.

16. Sebagai seorang User, saya ingin dapat melihat statistik penyelesaian aktivitas saya (jumlah yang selesai, ditunda, dibatalkan) agar bisa mengevaluasi produktivitas saya.

17. Sebagai seorang User, saya ingin dapat melihat distribusi aktivitas berdasarkan kategori agar bisa mengetahui pada aktivitas jenis apa saya menghabiskan waktu paling banyak.

18. Sebagai seorang User, saya ingin dapat melihat aktivitas berdasarkan filter kategori agar bisa fokus pada jenis aktivitas tertentu.

19. Sebagai seorang User, saya ingin dapat menerima notifikasi pengingat untuk aktivitas yang belum diselesaikan agar tidak melewatkan kegiatan penting.

20. Sebagai seorang User, saya ingin dapat melihat tampilan kalender bulanan dengan indikator aktivitas agar bisa melihat distribusi kegiatan dalam satu bulan.
