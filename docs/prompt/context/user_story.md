# User Stories untuk Aplikasi POS

| No | Stakeholder | Domain | User Story | Acceptance Criteria |
|----|------------|--------|------------|---------------------|
| 1 | Admin | Manajemen Pengguna | Sebagai Admin, saya ingin dapat membuat dan mengelola akun pengguna agar dapat mengatur hak akses dalam sistem | - Admin dapat membuat akun baru dengan role tertentu<br>- Admin dapat menonaktifkan/mengaktifkan akun<br>- Admin dapat mereset password<br>- Admin dapat melihat dan mengubah detail akun |
| 2 | Admin | Konfigurasi | Sebagai Admin, saya ingin mengatur parameter global sistem agar aplikasi dapat disesuaikan dengan kebutuhan bisnis | - Admin dapat mengatur nama aplikasi dan branding<br>- Admin dapat mengatur parameter pajak default<br>- Admin dapat mengatur format struk dan faktur<br>- Admin dapat mengatur kebijakan backup |
| 3 | Admin | Manajemen Lisensi | Sebagai Admin, saya ingin mengelola lisensi dan subscription agar memastikan pengguna mendapatkan fitur sesuai paket yang dibeli | - Admin dapat mengaktifkan/menonaktifkan lisensi<br>- Admin dapat melihat status lisensi<br>- Admin dapat memperpanjang lisensi<br>- Admin dapat upgrade/downgrade paket lisensi |
| 4 | Owner | Dashboard | Sebagai Owner, saya ingin melihat dashboard ringkasan bisnis agar dapat mengambil keputusan strategis dengan cepat | - Dashboard menampilkan pendapatan harian/mingguan/bulanan<br>- Dashboard menampilkan top 5 produk terlaris<br>- Dashboard menampilkan stok produk yang hampir habis<br>- Dashboard menampilkan grafik perbandingan penjualan |
| 5 | Owner | Manajemen Toko | Sebagai Owner, saya ingin mengatur informasi toko agar sesuai dengan identitas bisnis saya | - Owner dapat mengatur nama dan alamat toko<br>- Owner dapat mengupload logo toko<br>- Owner dapat mengatur nomor kontak dan email toko<br>- Owner dapat mengatur jam operasional toko |
| 6 | Owner | Laporan | Sebagai Owner, saya ingin mengakses laporan keuangan dan penjualan agar dapat memonitor kinerja bisnis | - Laporan dapat difilter berdasarkan periode waktu<br>- Laporan menampilkan laba kotor dan bersih<br>- Laporan dapat diekspor ke Excel/PDF<br>- Laporan menampilkan perbandingan dengan periode sebelumnya |
| 7 | Owner | Manajemen Staff | Sebagai Owner, saya ingin mengelola akun staff agar dapat mengatur struktur organisasi toko | - Owner dapat membuat akun kasir dan staff lain<br>- Owner dapat melihat aktivitas staff<br>- Owner dapat mengatur hak akses staff<br>- Owner dapat menonaktifkan akun staff |
| 8 | Cashier | Penjualan | Sebagai Cashier, saya ingin melakukan transaksi penjualan dengan cepat agar dapat melayani pelanggan dengan efisien | - Cashier dapat menambahkan produk dengan barcode scanner<br>- Cashier dapat mencari produk berdasarkan nama/kode<br>- Cashier dapat mengubah jumlah item<br>- Cashier dapat menampilkan total belanja |
| 9 | Cashier | Pembayaran | Sebagai Cashier, saya ingin memproses berbagai metode pembayaran agar dapat mengakomodasi preferensi pelanggan | - Cashier dapat menerima pembayaran tunai dan menghitung kembalian<br>- Cashier dapat memproses pembayaran QRIS<br>- Cashier dapat melakukan split payment<br>- Cashier dapat mencetak struk pembayaran |
| 10 | Cashier | Manajemen Transaksi | Sebagai Cashier, saya ingin dapat menahan transaksi sementara agar dapat melayani pelanggan lain terlebih dahulu | - Cashier dapat menyimpan transaksi untuk dilanjutkan nanti<br>- Cashier dapat memanggil kembali transaksi yang ditahan<br>- Cashier dapat mengelola beberapa transaksi paralel<br>- Sistem mencatat siapa yang menahan dan melanjutkan transaksi |
| 11 | Cashier | Return & Refund | Sebagai Cashier, saya ingin memproses pengembalian produk agar dapat menangani komplain pelanggan | - Cashier dapat mencari transaksi sebelumnya<br>- Cashier dapat memproses pengembalian sebagian atau seluruh item<br>- Cashier dapat mencatat alasan pengembalian<br>- Sistem mencatat history pengembalian |
| 12 | Inventory Staff | Manajemen Stok | Sebagai Inventory Staff, saya ingin mengelola stok produk agar persediaan selalu terpantau | - Staff dapat menambah stok masuk<br>- Staff dapat melakukan stock opname<br>- Staff dapat mencatat produk rusak/kadaluarsa<br>- Staff dapat melihat history perubahan stok |
| 13 | Inventory Staff | Produk | Sebagai Inventory Staff, saya ingin mengelola data produk agar katalog produk selalu update | - Staff dapat menambah produk baru<br>- Staff dapat mengubah informasi produk<br>- Staff dapat mengupload gambar produk<br>- Staff dapat mengkategorikan produk |
| 14 | Inventory Staff | Pengadaan | Sebagai Inventory Staff, saya ingin mengelola purchase order agar proses pengadaan terstruktur | - Staff dapat membuat purchase order<br>- Staff dapat mencetak purchase order<br>- Staff dapat menandai status PO (draft, sent, received)<br>- Staff dapat mencatat penerimaan barang dari PO |
| 15 | Owner | Analitik | Sebagai Owner, saya ingin melihat analitik performa produk agar dapat mengoptimalkan persediaan | - Owner dapat melihat produk fast/slow moving<br>- Owner dapat melihat margin profit per produk<br>- Owner dapat melihat tren penjualan per kategori<br>- Owner dapat mengidentifikasi produk yang perlu promo |
| 16 | Owner | Manajemen Diskon | Sebagai Owner, saya ingin membuat program diskon agar dapat meningkatkan penjualan | - Owner dapat membuat diskon per produk/kategori<br>- Owner dapat mengatur diskon berdasarkan periode waktu<br>- Owner dapat membuat diskon berbasis kuantitas<br>- Owner dapat melihat efektivitas program diskon |
| 17 | Cashier | Pelanggan | Sebagai Cashier, saya ingin mendata informasi pelanggan agar dapat mengelola program loyalitas | - Cashier dapat mendaftarkan pelanggan baru<br>- Cashier dapat mencari data pelanggan<br>- Cashier dapat melihat poin reward pelanggan<br>- Cashier dapat mengaitkan transaksi dengan pelanggan |
| 18 | All Users | Akun | Sebagai pengguna, saya ingin mengelola profil saya agar informasi pribadi tetap akurat | - Pengguna dapat mengubah data pribadi<br>- Pengguna dapat mengubah password<br>- Pengguna dapat mengatur preferensi UI<br>- Pengguna dapat melihat history login |
| 19 | Viewer | Katalog | Sebagai Viewer, saya ingin melihat katalog produk yang tersedia agar dapat mengetahui produk yang dijual | - Viewer dapat melihat daftar produk<br>- Viewer dapat mencari produk<br>- Viewer dapat melihat detail dan gambar produk<br>- Viewer dapat melihat ketersediaan stok |
| 20 | Owner | Ekspor Data | Sebagai Owner, saya ingin mengekspor data ke format umum agar dapat digunakan pada aplikasi lain | - Owner dapat mengekspor data penjualan ke Excel/CSV<br>- Owner dapat mengekspor data pelanggan<br>- Owner dapat mengekspor data stok<br>- Owner dapat mengatur periode data yang diekspor |
